Sell-side研究｜VT滞后减仓、CTA回补风险与亚洲波动率

科技急跌后分清策略与观察时点：散户由个股转向ETF，中国高频数据仍是托底与分化。

  4. 4. 中国：下行风险缓和，内需仍分化

Sell-side研究简报｜2026年11月6日

核心判断：科技急跌后，波动率目标策略仍有滞后减仓，但CTA转空后，反弹回补的不对称性增加。 散户近期由个股转向ETF；中国高频数据仍是托底与分化，并非全面复苏。

1. 美国：VT仍需卖，CTA方向分化

JPM在11月5日收盘后的报告估算，波动率目标策略未来数日需卖出约500亿美元股票敞口，目标杠杆由约67分位降至30分位。这是历史分位，不是仓位百分比；原文未明确地域范围。

CTA美国三大指数信号由11月2日前篇的中性转空。多数短信号已转空后，作者认为后续流量风险偏向反弹回补，但长期信号跌破仍可能触发续卖。

杠杆ETF在11月5日尾盘卖出估算超过600亿美元，约90%与科技相关，可能被抄底申购部分抵消。这是当日再平衡估算，不能与未来VT卖压加成“待卖1100亿美元”。每1%价格变动的隐含短Gamma敏感度约由75亿降至65亿美元，也不是Dealer Gamma。（11月5日，p1；前篇11月2日p2）

2. 散户：个股转净卖出，ETF仍在承接

10月29日至11月4日现金市场净买入25亿美元，前一周33亿；单股由净买4亿转为净卖23亿，ETF净买由29亿升至48亿。非Mag7科技由约净买1.9亿转为净卖18亿。

数据截止11月4日，不包含5日急跌；这是二级市场买卖失衡，不是基金申赎。（Retail Radar，印刷11月4日，p1、4、7、9；前期10月28日p1、3）

3. 亚洲：香港长端供给与日韩短端需求分开看

JPM的2027框架仍以香港单股结构产品为亚洲Vega主要供给源；日韩短端需求更强，韩国备兑ETF扩张可能缩短波动尖峰。香港前10个月单股产品月均发行约48亿美元，但存量敲出不足限制再发行。

最新香港Gamma图为正，按原图符号对应做市商short gamma；历史上“香港一般long gamma”的概括不能直接套用当前。报告中的NKY／恒科看涨价差方案发布于11月5日晚美股急跌之前，示意价格不是现价。（亚太衍生品，11月5日，p3–7、11–18、19–22）

4. 中国：下行风险缓和，内需仍分化

10月30城新房成交同比跌18.9%，较9月跌11.3%恶化；二手房同比增17.9%，较9月8.8%改善。乘用车零售同比跌25%。政府债发行1.12万亿元提供托底，但发行不等于已形成支出；离港船舶载重吨增10.6%是出口量代理，不是海关出口金额。（高频Series 66，11月6日，p2–8）

交易关注： 实现波动能否回落、CTA反弹回补是否出现，以及散户ETF买盘能否抵消其他卖压。上述不同策略、样本和观察时点的金额不能混加。
